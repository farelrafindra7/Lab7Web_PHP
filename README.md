# Praktikum 7 - Pemrograman Server-Side dengan PHP

## 1. Tujuan Praktikum
Praktikum ini bertujuan untuk mempelajari dasar-dasar pemrograman PHP sebagai bahasa pemrograman server-side, meliputi penggunaan variabel, percabangan, array, perulangan, function, GET, POST, dan validasi input pengguna.

## 2. Perangkat yang Digunakan
- Laptop atau komputer
- Visual Studio Code
- XAMPP
- PHP
- Web Browser

## 3. Cara Menjalankan Server Lokal
1. Instal dan buka aplikasi XAMPP.
2. Aktifkan Apache melalui XAMPP Control Panel.
3. Simpan folder proyek `Lab7Web_PHP` di dalam folder `htdocs`.
4. Buka browser.
5. Masukkan alamat `http://localhost/Lab7Web_PHP/` untuk menjalankan proyek.

## 4. Ringkasan Hasil Praktikum
- Latihan 1: Menampilkan teks dan tanggal menggunakan PHP.
- Latihan 2: Menggunakan variabel, operasi matematika, dan percabangan.
- Latihan 3: Menggunakan array dan perulangan foreach.
- Latihan 4: Membuat dan menggunakan function.
- Latihan 5: Mengolah input menggunakan metode GET.
- Latihan 6: Mengolah input menggunakan metode POST dan htmlspecialchars().
- Latihan 7: Membuat form transaksi dan validasi input.
- Mini Project: Membuat form data mahasiswa dengan validasi.
- Eksperimen Mandiri: Menghitung rata-rata, pencarian nama, format Rupiah, validasi NIM, dan tombol reset form.

## 5. Pengujian Input Valid dan Tidak Valid
### Input Valid
1. Form data mahasiswa diisi dengan nama, NIM 10 digit, program studi, semester yang sesuai, dan email dengan format benar.
2. Form transaksi diisi dengan nama barang, harga positif, dan jumlah pembelian positif.

### Input Tidak Valid
1. NIM diisi kurang dari 10 digit atau menggunakan huruf.
2. Form transaksi diisi dengan harga nol atau jumlah pembelian negatif.

## 6. Kesimpulan
Melalui praktikum ini, saya memahami dasar pemrograman PHP, penggunaan form, pengolahan data menggunakan GET dan POST, serta penerapan validasi input pada sisi server.
